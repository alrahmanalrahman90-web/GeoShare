Bagikan Lokasi Saya

Tekan tombol di bawah, lalu pilih Izinkan ketika browser meminta akses lokasi.

Cara mengaktifkan izin lokasi:
  1. Pastikan Lokasi/GPS perangkat aktif.
  2. Tekan ikon gembok/izin di sebelah alamat situs.
  3. Pilih Lokasi → Izinkan.
  4. Kembali ke halaman ini lalu tekan Coba Lagi.

Jika halaman dibuka sebagai file HTML langsung, gunakan HTTPS atau localhost agar lokasi browser dapat digunakan.
